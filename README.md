# NetInspect Advanced Binary Analyzer 4.0

Defensive Windows PE/static analysis and controlled runtime network triage.

Includes PE32/PE32+ parsing, section entropy, imports/exports, imported DLL
resolution and SHA-256, strings, hex preview, heuristic indicators,
Authenticode/version metadata, opt-in EXE runtime monitoring, process-tree
correlation, TCP/UDP snapshots, timeline-ready evidence and JSON/HTML export.

Run `build.bat` on Windows to create `dist\NetInspect-Advanced.exe`.

Static analysis never launches the selected file. Runtime execution is explicit
through the Runtime Network tab. Heuristics are indicators, not proof of malware.
